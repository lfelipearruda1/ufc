# Product

## Register

product

## Users

Estudante de computação apresentando um projeto acadêmico. O usuário primário durante avaliação é um professor ou banca técnica que abre o sistema para verificar funcionalidade e julgar qualidade de execução. O contexto é uma demonstração pontual, provavelmente em um notebook ou monitor de sala de aula. O sistema também serve como portfólio pessoal: recrutadores e outros desenvolvedores podem ver o projeto depois.

## Product Purpose

UFC Manager é um sistema de gerenciamento de dados do UFC construído como projeto acadêmico obrigatório com stack Java puro + JDBC no backend e JS puro no frontend (sem frameworks). Permite CRUD completo de lutadores, divisões, cards e lutas, além de expor views SQL (campeões, atividade), queries analíticas e logs de trigger. Sucesso significa que o projeto impressiona tanto pela solidez técnica quanto pela qualidade visual, diferenciando-se dos demais projetos da turma.

## Brand Personality

Brutal, preciso, autêntico. Tom direto e técnico, sem floreios corporativos. A personalidade é a de uma ferramenta que entende o esporte: dados densos tratados com respeito visual, não enterrados em formulários genéricos.

## Anti-references

- Bootstrap ou Material Design padrão: visual de sistema web genérico sem personalidade
- Dashboard financeiro SaaS: navy + ouro muito clean, parece fintech, frio demais para UFC
- Neon cyberpunk: roxo e rosa no preto, parece jogo dos anos 2010, sem relação com o esporte

## Design Principles

1. **O esporte aparece nos dados.** Cada tabela, badge e interação deve sentir que pertence a um contexto esportivo, não bancário. Hierarquia visual que respeita o peso dos atletas e resultados.
2. **Craft de portfólio.** É uma peça de demonstração; o nível de acabamento precisa ser visivelmente superior ao esperado para um projeto acadêmico.
3. **Denso mas respirável.** Ferramentas de dados exigem densidade. A legibilidade vem de tipografia disciplinada e espaçamento rítmico, não de esvaziar o layout.
4. **Institucional sem ser rígido.** UFC é hardcore e profissional ao mesmo tempo. O sistema deve sentir que poderia existir em uma transmissão oficial, não em um formulário de cadastro escolar.
5. **Referências reais como âncora.** ESPN App e UFC.com são as referências: tipografia forte, hierarquia esportiva, dados com contexto.
